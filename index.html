FCP Cleaner

自动扫描 · 安全清理 Final Cut Pro 的渲染文件、代理媒体和优化媒体。

下载最新版本 GitHub 仓库

凭什么能放心清

🤍 白名单机制

只认 Final Cut Pro 资源库结构中可被 FCP 重新生成的目录（渲染文件 / 代理媒体 / 优化媒体）。原始媒体、数据库、分析文件、未知目录、符号链接一律保护。

🗑️ 只进废纸篓

清理即移入 macOS 废纸篓，永不永久删除。清理历史记录每个原始位置，随时可定位恢复。

🚫 绝不自动清理

自动扫描只负责发现与分析。任何清理都需要你打开应用、查看清单、手动确认——没有例外。

🧾 三重执行前复核

执行前重新验证：Final Cut Pro 未在使用该库、磁盘在线可写、文件指纹与扫描时完全一致。任一条件不满足立即停止而不是猜测。

⚡ 中断可恢复

清理事务先落盘再执行。崩溃或断电后重启，会依据事务日志自动重建待清计划，重新走完整确认流程。

🔓 源码可见

安全边界全部在 FCPStructureRules 一个文件里定义，任何人可以审查我们到底会动哪些目录。

核心功能

  • 自动发现工作目录与本机所有卷中的 FCP 资源库，外置盘重新挂载后增量扫描
  • 体积趋势图表、周增长提醒、按卷低磁盘空间预警、定时检查
  • 按 Event 粒度勾选清理，清理前按磁盘历史速度估算耗时
  • 批量清理、清理历史一键恢复、Shortcuts 只读自动化查询
  • Final Cut Pro Workflow Extension：在 FCP 内把当前资源库一键交给 FCP Cleaner

更新

应用内置 Sparkle 自动更新（appcast）。要求 macOS 15.0 或更高版本；使用 Workflow Extension 需要 Final Cut Pro 12.3+。
